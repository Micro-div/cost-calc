# CostCalc — Global AI Cost Estimation and Quotation Platform

## 1. Project Overview

The proposed project is a worldwide AI powered cost estimation and quotation platform that helps users determine the expected cost, required work, resources and completion time for physical and digital projects.

A user will describe a project in simple language, select the project location and provide relevant details. The platform will analyze the requirements, ask additional questions where necessary and generate a localized cost estimate.

The estimate will include:

* Minimum, average and maximum expected cost
* Labour cost
* Material cost, where applicable
* Equipment and third party expenses
* Taxes, markup and contingency
* Estimated completion time
* Detailed scope of work
* Assumptions and possible additional costs
* Estimate confidence level
* Editable professional quotation
* Downloadable PDF and shareable web link

The long term objective is to create a platform where anyone can estimate the cost of almost any physical or online project before hiring a professional or starting the work.

## 2. Product Vision

The platform will become a global starting point for answering the question:

> How much should this project cost?

Instead of searching different websites, contacting multiple service providers or depending on an unverified AI generated price, users will receive a structured and transparent estimate based on project requirements, location, market rates and historical data.

The platform will eventually connect users with verified service providers who can review the project and submit real quotations.

## 3. Core Value Proposition

The platform will allow users to:

* Describe any project in natural language
* Receive an instant localized cost range
* Understand how the total cost was calculated
* Review labour, materials and other expenses separately
* Compare basic, standard and premium options
* Generate a professional quotation
* Request actual quotes from relevant professionals
* Compare provider prices before hiring
* Save time and avoid unrealistic pricing

The primary value will not be limited to generating quotation documents. The platform will help users understand what a project should realistically cost in their selected location.

## 6. User Estimation Process

### Step 1: Describe the Project

The user will enter the project requirement in natural language.

Example:

> I need an ecommerce website for a clothing brand in Canada. It should support online payments, customer accounts and approximately 500 products.

For physical work:

> I want to renovate a small kitchen in Toronto using standard quality materials.

The platform will also provide category based options for users who prefer not to write a complete description.

### Step 2: Extract Requirements

The AI will identify:

* Project category
* Required features
* Country and city
* Project size
* Quality preference
* Required resources
* Expected deadline
* Missing information
* Possible risks

### Step 3: Ask Additional Questions

The platform will ask one relevant question at a time.

Examples:

* Where will the project be completed?
* What is the total project size?
* Which quality level do you require?
* Do you already have a design?
* Are materials included?
* What is your preferred completion date?
* Do you need maintenance after completion?

Questions will change dynamically based on the selected category.

### Step 4: Confirm Requirements

The user will review the detected requirements before generating the estimate.

The user can:

* Add missing requirements
* Remove unnecessary items
* Change the project location
* Select a different quality level
* Upload images or documents
* Confirm the final scope

### Step 5: Generate Estimate

The platform will calculate the estimated project cost and display the result in a clear dashboard.

### Step 6: Edit and Export

The user will be able to:

* Edit quantities
* Change rates
* Add or remove line items
* Apply taxes
* Add discounts
* Add profit margin
* Add contingency
* Generate a quotation
* Download a PDF
* Create a shareable link

### Step 7: Request Real Quotations

The user may optionally submit the project to relevant service providers.

Providers will be able to:

* Review project details
* Ask questions
* Submit actual quotations
* Provide estimated timelines
* Add terms and conditions

The user can then compare providers and quotations.

### Assumptions

The estimate will clearly state any assumptions used during calculation.

Examples:

* Existing electrical wiring is assumed to be functional
* Content will be provided by the client
* Hosting and domain charges are not included

The result will explain which factors may increase or reduce the final cost.

### Confidence Level

Every estimate will receive a confidence level:

* High confidence
* Medium confidence
* Low confidence
* Professional inspection required

A confidence level will be calculated based on:

* Completeness of user information
* Availability of local pricing data
* Number of similar estimates
* Age of available price data
* Complexity of the project
* Requirement for physical inspection

## 8. Estimation Methodology

The platform will use a hybrid estimation system instead of allowing AI to invent prices.

The estimated amount will be based on:

* Base market rate
* Country and city multiplier
* Project size
* Project complexity
* Quality level
* Estimated working hours
* Labour rate
* Material rate
* Equipment cost
* Taxes
* Profit margin
* Contingency percentage
* Historical estimate data
* Actual completed project data

A simplified calculation model will be:

> Base Rate × Location Multiplier × Size × Complexity + Labour + Materials + Equipment + Taxes + Contingency

Artificial intelligence will be used to:

* Understand project descriptions
* Convert descriptions into structured requirements
* Identify missing information
* Generate project tasks
* Prepare scope of work
* Explain estimate results
* Generate professional quotation content

The rule based pricing engine will be responsible for:

* Cost calculations
* Regional rates
* Currency conversion
* Taxes and percentages
* Minimum and maximum ranges
* Confidence score
* Mathematical accuracy

## Add base path in Next.js when unique domain is disabled

If you [disable the unique domain](https://docs.gitlab.com/user/project/pages/#unique-domains),
the site will be hosted under `yourname.gitlab.io/examplerepository/`,
you will need to configure Next.js to use the `basePath`.

In `next.config.mjs`, the value for `basePath` should be your project’s name,
starting with a forward slash - for example, `/examplerepository`.
This ensures Next.js understands that your website’s root is `/examplerepository` instead of the default `/`,
especially when your project is hosted at `https://gitlab.com/yourname/examplerepository/`.

```js:title=next.config.mjs
const nextConfig = {
  basePath: '/examplerepository',
};
export default nextConfig;
```
